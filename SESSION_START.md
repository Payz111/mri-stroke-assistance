# Протокол начала сессии разработки

> **Для Рината:** В Claude Code контекст сохраняется автоматически через auto memory.
> Для подстраховки можно начать сессию фразой ниже.

---

## Стартовый промпт (если нужен)

```
Продолжаем работу над MRI Stroke Assist.
Прочитай PROJECT_STATE.md и CURRENT_TASK.md, предложи следующие шаги.
```

---

## Что Claude Code делает при старте сессии

1. **Читает auto memory** (MEMORY.md) — загружается автоматически в system prompt
2. **Читает PROJECT_STATE.md** → текущая фаза и прогресс
3. **Читает CURRENT_TASK.md** → конкретная задача с чек-листом
4. **Проверяет DECISIONS.md** (если нужен контекст решений)
5. **Предлагает** продолжить текущую задачу или перейти к следующей

---

## Что Claude Code делает в конце сессии

По просьбе "обнови файлы состояния":

1. **PROJECT_STATE.md** — прогресс по Gate'ам, история сессий
2. **CURRENT_TASK.md** — чек-лист, заметки, следующая задача
3. **DECISIONS.md** — новые ADR если были решения
4. **MEMORY.md** — обновление auto memory при необходимости

---

## Файлы контекста

```
project root/
  PROJECT_STATE.md    # Главный файл (читать ПЕРВЫМ)
  CURRENT_TASK.md     # Детали текущей задачи
  DECISIONS.md        # Архитектурные решения (ADR)
  SESSION_START.md    # Этот файл (инструкции)

~/.claude/projects/.../memory/
  MEMORY.md           # Auto memory Claude Code (system prompt)
```

## Советы для эффективной работы

### Хорошие промпты
- "Продолжаем. Прочитай PROJECT_STATE и скажи что дальше."
- "Давай реализуем preprocessing pipeline."
- "Застрял на регистрации DWI->FLAIR. Вот ошибка: [error]."
- "Обнови файлы состояния проекта."

### Если контекст потерян
1. Claude Code прочитает MEMORY.md автоматически
2. Попроси: "Прочитай PROJECT_STATE.md и CURRENT_TASK.md"
3. В крайнем случае — контекст восстановится из файлов проекта
